# Аналитика логистики и эффективности доставки

## О проекте
Сквозной аналитический проект по исследованию логистики и эффективности процессов доставки. Я прошел полный цикл работы с данными: от очистки сырого датасета в Python до глубокого анализа через SQL-запросы и построения интерактивного дашборда в Power BI для отслеживания KPI.

### Стек технологий
* **Python** (Pandas, NumPy, Matplotlib, Seaborn) — первичный аудит, очистка данных и разведочный анализ (EDA).
* **MySQL** — бизнес-анализ, сегментация и ранжирование данных.
* **Power BI и DAX** — интерактивная визуализация и расчет метрик.

---

## Основные выводы и метрики
* **Общие показатели:** Среднее время доставки по всему датасету составляет около 125 минут. Средний рейтинг курьеров — 4.6, что говорит о стабильно высоком качестве сервиса.
* **Главная причина задержек — Пробки:** Тяжелые дорожные заторы (Jam) приводят к максимальному времени ожидания. Пробки — это ключевой фактор логистических сбоев.
* **Влияние погоды:** Туман (Fog) и сильная облачность (Cloudy) заметно увеличивают время доставки по сравнению с солнечными днями.
* **Распределение транспорта:** Скорость доставки напрямую зависит от типа транспорта. При этом мотоциклы берут на себя наибольший объем заказов.
* **Объемы по регионам:** Мегаполисы (Metropolitan) генерируют больше всего заказов. В полу-городских зонах (Semi-Urban) заказов меньше всего, но там зафиксированы самые долгие задержки из-за слабой инфраструктуры.
* **Специфика категорий:** Доставка продуктов (Grocery) выполняется быстрее всего по сравнению со всеми остальными категориями товаров.
* **Интерактивный анализ:** KPI-карточки и срезы в Power BI позволяют быстро фильтровать и анализировать эти метрики в любых комбинациях.

## Что было сделано в ходе разработки

### 1. Предобработка данных (Python)
* Удалил дубликаты и пропуски, очистил текстовые поля от скрытых пробелов.
* Привел даты к формату datetime для корректного анализа временных рядов.
* Построил матрицу корреляции для поиска связей между параметрами курьеров и временем доставки.

### 2. База данных (MySQL)
Написал комплекс аналитических запросов, где применил:
* Оконные функции (`RANK() OVER`) для вычисления рейтинга курьеров.
* Оптимизацию через обобщенные табличные выражения (`WITH / CTE`) для поиска заказов с аномально долгой доставкой.
* Кастомную сегментацию заказов (`Fast / Medium / Slow`) через условную логику.

### 3. Визуализация (Power BI)
* Разработал модель данных и создал кастомные меры на языке DAX для расчета процента задержек.
* Настроил интерактивный дашборд с удобной фильтрацией по погоде, типу транспорта и регионам.
